# minecraft-autonomous-agent
A Javascript Minecraft bot built with mineflayer, capable of finding, navigating to, and mining resources

#Current Features
1. Nearest resource detection
2. Automatic pathfinding
3. Breaking said resource

#Technologies
1. Javastcript
2. Node.js
3. Mineflayer
4. Mineflayer-pathfinding

#Usage
```bash
git clone https://github.com/Kaan-B-Aydin/minecraft-autonomous-agent.git
cd minecraft-autonomous-agent
npm install
npm start
```
